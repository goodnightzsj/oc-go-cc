# 日志、套餐和统计兼容

## Task Shape

single-full；依赖03-commandcode最终验收。

## Goals

- 五个平台均有独立设置、日志筛选、平台与模型归属；保存局部配置不丢失未提交字段、不回显或持久化密钥掩码。
- 未知价格/用量/请求状态明确显示未知，不当作免费、成功或满额度；UTC筛选和趋势一致。
- CommandCode套餐只展示有依据的能力与官方Usage/Billing入口，不复用OpenCode Go额度。
- 修复小额费用分布比例，执行合成DOM与真实浏览器冒烟。
- 2026-09-11 重开：补齐 Overview、Performance、Analytics 的独立平台查询与切换；同名模型、前期对比、趋势与汇总必须使用同一范围。
- 套餐查询按五平台官方合同分别核实，接入有依据的接口。所有平台都有真实本地用量视图，但不得以本地费用代替账户余额；未提供/无权限/配置缺失/上游失败/已获取须可区分。

## Constraints

保留现有UI设计和原生JS，不安装依赖，不操作真实账户，测试只使用合成数据。浏览器/操作系统未覆盖的范围如实记录。

## Done-When

配置、历史、性能、统计和套餐逐平台回归通过；小额/零/未知费用与平台切换竞态有回归；官方接口证据和缺口被明确记录；浏览器关键交互完成。仅占位不能视为真实套餐接入完成。

## Validation

`go test -race ./internal/storage ./internal/gui`、`node --check internal/gui/assets/app.js`及隔离浏览器冒烟。
