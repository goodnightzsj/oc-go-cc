# CommandCode 真实套餐接口核实与接入

## Task Shape

single-full；父任务 #9。

## Goals

- 使用 edge-debug-attach 的单一长连接，只读查看用户已登录 CommandCode 的套餐/用量页面及相关网络协议。
- 区分推理 API Key 与网页会话；明确端点、方法、字段、时间/币种/额度单位、权限和缓存。
- 只实现有真实证据并可由既有授权调用的账户查询；缺少服务端认证来源时显式记录，不猜测或导出 Cookie。

## Constraints / Non-Goals

不重启浏览器、不读取或输出凭证、不购买/变更套餐、不发起真实付费生成、不改用户全局客户端配置。不将本地账本冒充官方消费。其他平台未知/未授权状态保留。

## Environment / Validation

Go + 内嵌原生前端；隔离 HOME/DB 的 quota/gui 合成回归，必要时应用侧真实只读 GET 与页面核对。浏览器原始资料仅保留脱敏的任务相关字段。

## Done-When

端点与认证证据落盘；可用能力有针对性成功/失败回归并连到套餐 UI；浏览器专用能力的服务端限制明确，未经授权不绕过。
