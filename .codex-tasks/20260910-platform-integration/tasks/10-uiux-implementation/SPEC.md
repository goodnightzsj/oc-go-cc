# 多平台 UI/UX 美化实施

## Task Shape

single-full；父任务 #10；既有分析见 docs/uiux-multiplatform-review.md。

## Goals

- 七页保持平台隔离与费用定义，改善历史首屏、设置平台定位、套餐官方/本地层级、表格可读性与浅深主题。
- 补全原生键盘排序、备用链上移/下移、开关名称、图表读数；响应式触摸区与焦点可见。
- 保留五平台全部独立字段、局部 PATCH、脱敏、AWS 显式收费边界与未知/错误状态。

## Constraints / Non-Goals

沿用原生 HTML/CSS/JS、靛蓝主色、系统可用字体，无新增 UI 依赖，不重写框架或业务模型，不对真实账户使用测试配置/数据。

## Deliverables / Done-When

定向 DOM/键盘/响应式回归；全量 race/vet 与必要跨平台构建通过；提交推送并按既有脚本部署，再使用 edge-debug-attach 的同一连接在已登录远端面板验收五平台七页、双语双主题与关键状态。2026-09-11 用户明确不用新浏览器/合成服务代替远端调试；保留配置/账本和回滚路径，不在生产保存测试配置或发起付费查询。
