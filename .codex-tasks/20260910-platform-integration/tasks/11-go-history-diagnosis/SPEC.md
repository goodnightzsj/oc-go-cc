# 远端 OpenCode Go 旧数据消失诊断

## Goal / Scope

只读确认现用数据库、原始账单、请求展示表、已有备份及清理/同步链路，解释旧 Go 数据不再显示的原因及可恢复范围。用户要求分析，未授权恢复、重算、回填或调整保留策略。

## Constraints

不读取凭证或对话；仅查询表结构、计数、时间范围和必要聚合。SQLite使用readonly；不执行VACUUM、同步命令、迁移或服务重启。Edge复用原连接。已有用户修改保留。

## Acceptance

运行DB路径、表计数、备份对比、实际保留设置有证据；区分确认的行为与无法追溯的删除时刻；报告恢复来源与需要的授权。诊断不改写真实数据。
