# 参考 sub2api / new-api 的七页控制台重设计

## Goal

用户明确认为上一轮部分页面不好看，要求全部页面及数据呈现重新设计。参考sub2api/new-api的管理控制台信息架构，而非仅换配色；包括概览、历史、性能、降级策略、分析、套餐和设置。

## Direction / Constraints

保留Go、SQLite、原生HTML/CSS/JS和五平台接口；不引入参考项目的后端、组件依赖、品牌资源或未经许可代码。原配置PATCH、缓存Token、未知费用、官方账单与本地记录边界保持。浅深主题、中英文、键盘和320px以上布局均需覆盖。使用既有设计语境：面向开发者/运维，清晰、专业、可信。

## Acceptance

七页均有清楚的主次关系、可读数据表、可定位的平台设置和解释性的空态；真实UI与参考方向有可观察的变化。完整定向/全量回归及静态构建通过，随后按已授权流程提交部署，在既有Edge验收，保留账本配置和回滚路径。真实业务数据为空时明确覆盖缺口，不往生产插入测试数据。
