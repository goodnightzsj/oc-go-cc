# 关闭清理与官方历史恢复

## Task Shape / Goals

single-full。关闭远端请求自动清理；从本项目Claude session提取最终OpenCode同步与Token拆分方法；获取官方全部可见用量并与真实备份对账，恢复可证明的历史记录。

## Constraints / Non-Goals

用户2026-09-12已授权真实数据修改。必须先独立备份配置/数据库并在副本演练；只恢复必要表和字段，不用旧库覆盖现库，不影响其他平台，不猜测成功率/延迟。原始官方费用、纯输入与缓存拆分为权威，缺失值不能补零假成功。凭证由现有服务/浏览器使用，不读取或输出；不修改本地其它项目日志。完整业务数据仅存权限受限临时目录，不提交仓库。

## Environment / Risks

Go+SQLite；现有costs工具与原生HTML/JS。基线560a11f，生产程序b3c947d。旧脚本有固定server hash/workspace、金额相等即配对和无备份插入，必须以当前协议和测试核实，不能直接执行旧--apply。

## Done-When

官方分页终点与唯一ID计数可验证；备份/现库/官方有差异报告；自动清理关闭且未配置用户默认行为保持；恢复事务有可回滚来源，重复执行不增行；Token和费用对账通过，页面真实显示恢复数据。
